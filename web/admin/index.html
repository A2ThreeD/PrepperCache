              About PrepperCache

              PrepperCache turns a Raspberry Pi into a local hub for offline reference books, preparedness guides, maps, and optional learning resources. Once downloaded, the library and maps are available to devices on the same network without internet access.

              Written by Aaron Morris / A2ThreeD.

              Project credits

              • Kiwix and openZIM power the offline library. Project Gutenberg provides the classic books collection.
              • MapLibre GL JS renders the map. Protomaps provides the basemap and PMTiles tooling. Map data © OpenStreetMap contributors.
              • The PrepperPi catalog inspired PrepperCache’s map downloading workflow and provides the starting point for country bounds, bundles, and size estimates. The U.S. Census Bureau provides state boundaries.
              • Project NOMAD inspired PrepperCache’s installation style and the types of content included in its offline library.
              • Kolibri by Learning Equality provides optional offline learning.
              • Raspberry Pi OS and NGINX provide the operating system and web server.
